# KongGate: the screens

The app's screens (React, TypeScript, Vite), built into static files that the
desktop app's engine serves. How to build, develop and release the app is in
the [README at the root](../README.md).

```bash
npm install
npm run dev     # with the engine running beside it: see the root README, "Develop"
npm run build   # what desktop/build.mjs runs
```
